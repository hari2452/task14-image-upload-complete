TASK 14 – QUICK EXPLANATION NOTES

1. User selects image in React.
2. URL.createObjectURL(file) shows instant temporary preview.
3. On submit React creates FormData.
4. FormData sends the real file to POST /api/upload.
5. Flask checks allowed extension and 2 MB limit.
6. secure_filename cleans the original filename.
7. UUID creates a unique filename to avoid overwrite conflicts.
8. Flask saves the file in backend/static/uploads.
9. Flask returns a relative path such as /static/uploads/abc123.jpg.
10. React sends this relative path in POST /api/products or PUT /api/products/:id.
11. MySQL stores only image_url, not the actual image.
12. Home and Product Detail display:
    http://localhost:5000 + product.image_url
13. After refresh React fetches the saved path again, so the image persists.
14. When replacing an image, upload the new image first, update the DB path, then delete the old physical image.
15. useToast shows success/error feedback and disappears automatically after 3 seconds.
